# ekatra-hub
Ekatra Hub: a BB10 Hub-inspired unified inbox for Android. See all your notifications in one place, reply from a single timeline, and swipe up to peek. 100% on-device, no data ever leaves your phone.

## Getting started
New to Android development? Follow [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md): it covers setting up your PC and phone, running the app, and making it smooth.
